# Audit of the original capstone notebook

Generated by `python -m covid_risk.capstone` from `data/covid_capstone.csv.gz`.

## The extract

- 199,999 patients, 41,407 deaths (**20.7%**); deaths dated 2020-01-02 to 2021-05-02.
- 125,590 rows are exact copies of another row. They are different patients with the same profile: 86.5% of survivors share a row with someone else (largest group: 552 identical people), against 2.9% of deaths (each death has its own date).
- Dropping them removed 124,985 survivors but only 605 deaths, raising the death rate to **54.8%**.
- `ICU` is identical to `PATIENT_TYPE` (hospitalised) in every row: True. Intubation code 3 marks exactly the outpatients: True.
- Intubation status 'unknown' (code 4): death rate 74.5%, a recording artefact.
- Pneumonia code 99 (missing) in 4,756 rows; summed into the notebook's comorbidity score it creates scores up to 108.
- Death rate by `CLASIFFICATION_FINAL` (1-3 = confirmed COVID; 2 = confirmed by committee, a code used only for deaths; 4-7 = not confirmed):
